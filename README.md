# HabbitTracker
HabitTracker API — High-performance RESTful API for tracking habits and routines, built with ASP.NET Core, EF Core, PostgreSQL, and Redis

A robust RESTful API for tracking personal habits, routines, and daily progress. Built with ASP.NET Core (.NET 8) following Clean Architecture principles, with a focus on database performance, data consistency, and strict input validation.

### Tech Stack
- **Framework:** ASP.NET Core Web API (.NET 8)
- **Database & ORM:** PostgreSQL / Entity Framework Core
- **Caching:** Redis (Distributed caching & Cache-aside pattern)
- **Validation:** FluentValidation
- **Documentation:** Swagger / OpenAPI
- **Containerization:** Docker & Docker Compose
